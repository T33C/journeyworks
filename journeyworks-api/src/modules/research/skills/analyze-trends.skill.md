# Analyze Trends

## Description

Time-series analysis showing volume, sentiment, and topic trends over any period, filterable by product.

## When to Use

- User asks about trends over time — volume, sentiment, or topic changes
- "How has communication volume changed...", "Show me sentiment trends...", "Are complaint volumes increasing or decreasing?"
- Time-series analysis questions

## Examples

- "How has communication volume changed over the past month?"
- "Show me sentiment trends for the Cash ISA product"
- "Are complaint volumes increasing or decreasing?"
