# Ask Question

## Description

Ask a natural-language question and get a direct answer synthesised from the knowledge base, with a confidence score.

## When to Use

- User asks a direct question about a customer or event
- Questions that need a synthesised answer from multiple documents
- "Why did...", "What was the outcome of...", "What happened with..."

## Examples

- "Why did customer C-1042 contact us last week?"
- "What was the outcome of the mortgage dispute?"
