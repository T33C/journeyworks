# Get Customer Info

## Description

Get a full customer profile including recent communications, contact history, and a relationship summary.

## When to Use

- User asks about a specific customer by name or ID
- "Tell me about customer...", "What's the communication history for..."
- User wants a customer profile or contact history overview

## Examples

- "Tell me about customer C-1042"
- "What's the communication history for Acme Corp?"
