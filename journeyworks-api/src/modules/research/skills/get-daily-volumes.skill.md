# Get Daily Volumes

## Description

Daily volume counts for communications or cases, with filters for channel, category, status, and product.

## When to Use

- User asks for daily counts or volumes
- "How many cases per day...", "Show me daily email volumes...", "What's the daily complaint rate..."
- Questions involving daily breakdowns of communications or cases

## Examples

- "How many cases are we getting per day?"
- "Show me daily email volumes for last week"
- "What's the daily complaint rate for CDD Remediation?"
