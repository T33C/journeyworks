# Analyze CDD Cases

## Description

Analyse Customer Due Diligence remediation cases — volumes, reason breakdowns, status tracking, and trends.

## When to Use

- User asks about CDD remediation cases
- "How many CDD cases...", "What are the top reasons for CDD remediation?", "Break down CDD cases..."
- Questions about Customer Due Diligence volumes, statuses, or reasons

## Examples

- "How many CDD cases are open?"
- "What are the top reasons for CDD remediation?"
- "Break down CDD cases by status and reason"
