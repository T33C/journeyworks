# Find Similar

## Description

Find communications that are similar to a specific one — useful for spotting patterns or related issues.

## When to Use

- User wants to find communications similar to a known one
- Looking for patterns or related issues across customers
- "Find communications similar to...", "Are there other customers reporting the same issue?"

## Examples

- "Find communications similar to this mortgage complaint"
- "Are there other customers reporting the same issue?"
