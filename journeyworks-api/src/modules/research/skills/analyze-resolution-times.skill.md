# Analyze Resolution Times

## Description

Statistics on how long cases take to resolve (average, min, max), broken down by category.

## When to Use

- User asks about resolution times, how long cases take
- "What's the average resolution time...", "How long are cases taking to resolve?", "Which category has the longest resolution times?"
- Looking for resolution time statistics

## Examples

- "What's the average resolution time for CDD cases?"
- "How long are cases taking to resolve?"
- "Which category has the longest resolution times?"
