# Detect Issues

## Description

Automatically identify recurring problems, systemic issues, and urgent complaints from negative-sentiment communications.

## When to Use

- User asks about recurring issues, systemic problems, or urgent complaints
- "Are there any recurring issues...", "What systemic problems...", "Detect urgent complaints..."
- Looking for patterns in negative customer experiences

## Examples

- "Are there any recurring issues we should be aware of?"
- "What systemic problems are customers reporting?"
- "Detect urgent complaints from the last 7 days"
