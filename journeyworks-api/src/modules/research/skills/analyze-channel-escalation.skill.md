# Analyze Channel Escalation

## Description

Track how often communications escalate between channels (e.g., chatbot to human agent, email to phone).

## When to Use

- User asks about escalations between channels
- "How many chatbot conversations escalate to a human agent?", "What's the escalation rate..."
- Looking for escalation patterns between communication channels

## Examples

- "How many chatbot conversations escalate to a human agent?"
- "What's the escalation rate from email to phone?"
- "Show me escalation patterns for CDD cases"
