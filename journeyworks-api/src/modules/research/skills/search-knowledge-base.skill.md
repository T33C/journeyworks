# Search Knowledge Base

## Description

Semantic search across all customer communications — finds emails, call transcripts, chat logs, and documents relevant to any topic or question.

## When to Use

- User wants to find specific communications, emails, call transcripts, or chat logs
- User asks to search for mentions of a topic across all customer data
- Queries starting with "Find all communications...", "Search for...", "What have customers said about..."
- User wants to discover what exists in the knowledge base about a subject

## Examples

- "Find all communications mentioning account closures"
- "What have customers said about the new fee changes?"
- "Search for complaints about payment failures"
