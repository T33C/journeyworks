# Get Category Breakdown

## Description

Breakdown of communications or cases by category and subcategory — shows top complaint reasons and volumes.

## When to Use

- User asks for breakdowns by category or subcategory
- "What are the top complaint categories?", "Break down cases by category...", "What are customers complaining about most?"
- Looking for category distributions or top reasons

## Examples

- "What are the top complaint categories?"
- "Break down cases by category and subcategory"
- "What are customers complaining about most?"
