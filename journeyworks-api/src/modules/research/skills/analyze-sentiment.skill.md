# Analyze Sentiment

## Description

Break down sentiment (positive, neutral, negative) across communications, filterable by customer, time range, channel, or product.

## When to Use

- User asks about customer sentiment or mood
- Questions about positive, negative, or neutral communication trends
- "What's the overall sentiment...", "How is sentiment trending...", "Show me sentiment breakdown..."

## Examples

- "What's the overall customer sentiment this month?"
- "How is sentiment trending for the Advance Account?"
- "Show me sentiment breakdown by channel"
