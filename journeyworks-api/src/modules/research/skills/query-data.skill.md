# Query Data

## Description

Translate natural-language questions into structured data queries — use for counting, filtering, aggregating, and slicing data.

## When to Use

- User asks for counts, totals, percentages, or aggregations
- Questions involving filtering and slicing structured data
- "How many...", "Count...", "What percentage..."

## Examples

- "How many emails did we receive last week?"
- "Count complaints by channel for January"
- "What percentage of cases are still open?"
